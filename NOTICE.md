# Training Data Attribution

Haru was trained on
[Tiny-Ko-Stories](https://huggingface.co/datasets/psymon/Tiny-Ko-Stories) by
psymon, licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

The source dataset is not redistributed in this repository or in the Haru
model repository. It was tokenized and split into training and validation
streams for model training.
